# Сборщик и объединитель Excel файлов

Скрипт для сбора, копирования и объединения всех Excel файлов из папки "файлы" или любой другой указанной папки.

## Возможности

- 🔍 Поиск всех Excel файлов (.xlsx, .xls, .xlsm, .xlsb) в указанной папке и подпапках
- 📊 Отображение подробной информации о каждом файле (размер, дата изменения)
- 📈 Подсчет общего количества и размера найденных файлов
- 📦 Возможность копирования всех найденных файлов в одну папку
- 🔗 **НОВОЕ!** Объединение всех Excel файлов в один файл
- 🏷️ Автоматическое добавление колонки с именем исходного файла
- 📋 Поддержка выбора конкретного листа для объединения
- 🔄 Автоматическое переименование при конфликтах имен

## Установка зависимостей

Для функции объединения файлов требуются дополнительные библиотеки:

```bash
pip install -r requirements.txt
```

или

```bash
pip install pandas openpyxl
```

## Использование

### Просто показать все Excel файлы из папки "файлы":
```bash
python collect_excel_files.py
```

### Показать файлы из другой папки:
```bash
python collect_excel_files.py -s "мои_документы"
```

### Скопировать все найденные файлы в папку "собранные_excel":
```bash
python collect_excel_files.py -d "собранные_excel"
```

### 🔗 Объединить все файлы в один:
```bash
python collect_excel_files.py -m "объединенный.xlsx"
```

### Объединить файлы из конкретной папки:
```bash
python collect_excel_files.py -s "данные" -m "результат.xlsx"
```

### Объединить конкретный лист (например, "Лист1"):
```bash
python collect_excel_files.py -m "итог.xlsx" --sheet "Лист1"
```

### Объединить без добавления колонки с именем файла:
```bash
python collect_excel_files.py -m "итог.xlsx" --no-source-column
```

### Скопировать И объединить одновременно:
```bash
python collect_excel_files.py -d "копии" -m "объединенный.xlsx"
```

## Параметры

- `-s, --source` - Папка-источник (по умолчанию: "файлы")
- `-d, --destination` - Папка назначения для копирования файлов
- `-m, --merge` - Объединить все файлы в один (указать имя выходного файла)
- `--sheet` - Имя листа для чтения при объединении (по умолчанию: первый лист)
- `--no-source-column` - Не добавлять колонку с именем исходного файла
- `-h, --help` - Показать справку
